# crop-yield-prediction
Crop Yield Prediction System is a full-stack web application built with Python, Flask, and Machine Learning that predicts crop yield based on inputs like rainfall, temperature, crop type, and land area. It features user authentication, an interactive dashboard, and visual analytics using Chart.js. Built as an MCA Final Year Project.

# 🌾 Crop Yield Prediction System

A full-stack Machine Learning web application that predicts crop yield based on
environmental and agricultural inputs such as rainfall, temperature, crop type,
and land area.

Built as an MCA Final Year Project using Python, Flask, and Scikit-learn.

---

## 🚀 Live Demo

> Run locally at: `http://127.0.0.1:5000`
> Login: **admin** / **admin123**

---

## 📌 Features

- 🔐 **User Authentication** — Login & logout with session handling
- 🤖 **ML Powered Predictions** — RandomForestRegressor trained on crop data
- 📊 **Interactive Dashboard** — View all past predictions in a table
- 📈 **Analytics Page** — Bar chart, Pie chart, and Line chart using Chart.js
- 💾 **SQLite Database** — Stores all predictions with timestamp
- 🎨 **Clean Responsive UI** — Built with HTML, CSS, and Poppins font
